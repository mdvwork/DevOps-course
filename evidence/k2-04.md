Что сделано: Развёртывание локального Docker Registry (registry:3.0.0), тегирование локального образа и проверка полного цикла дистрибуции (push/pull).
Команды и существенный вывод:
docker compose --profile registry up -d registry
docker tag devops-student:v1 localhost:5000/workshop:v1
docker push localhost:5000/workshop:v1
docker pull localhost:5000/workshop:v1

Ожидал: Успешная выгрузка образа в локальный реестр и его последующая загрузка обратно.
Получил: Все слои образа успешно отправлены (Pushed) и стянуты без ошибок, дайджест образа совпал.
Почему это подтверждает результат: Консоль зафиксировала успешную передачу слоев и подтвердила статус Image is up to date.
Ошибка и её исправление (если были): Ошибок не возникало, порты локального реестра (5000) были свободны.
Ответ на вопрос из задания: Локальный registry позволяет тестировать процессы дистрибуции образов в изолированном контуре без обращения к внешним облачным реестрам.

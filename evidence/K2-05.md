# K2-05. Ошибка конфигурации

- Группа и код студента: ИТ9.24.1
- Действия: временно изменено `API_URL` в `compose.student.yaml` на `http://api:9999`; выполнено `docker compose -f compose.student.yaml up -d web`; проверен HTTP GET `/api/requests` и `docker compose -f compose.student.yaml logs --tail=8 web`. Затем восстановлено `http://api:8000`, повторно выполнено `up -d web`, проверены GET и POST `/api/requests`.
- Наблюдения при ошибке: ответ `{"error":"upstream_unavailable","request_id":"a88280b0"}` (HTTP 503). В логах `web`: `"event": "upstream_unavailable", "target": "http://api:9999", "error": "<urlopen error [Errno 111] Connection refused>"`; далее `GET /api/requests` со статусом 503.
- Причина: `api` слушает внутри сети Compose порт 8000, а не 9999. Сам `web` запускается, но связаться с `api` по неверному порту не может.
- После исправления: GET вернул список с заявками №1–3, а POST создал новую заявку №4 (`screen`). В итоговом Compose-файле восстановлено `API_URL: http://api:8000`.
- Ответ на вопрос: `web` должен использовать `api:8000`; порт 8080 опубликован для доступа с компьютера к `web`, а не для связи с `api`.

Что сделано: Развёртывание и управление циклом контейнеров с помощью Docker Compose на macOS (Apple Silicon). Проверка остановки и запуска сервисов.
Команды и существенный вывод:
docker compose -f compose.student.yaml up -d
docker compose -f compose.student.yaml stop web
docker compose -f compose.student.yaml start web

Ожидал: Успешный запуск и управление контейнерами.
Получил: Создание сети, томов и запуск контейнеров.
Почему это подтверждает результат: Статусы контейнеров стали рабочими, приложение стало доступно по порту.
Ошибка и её исправление (если были): При попытке выполнить docker compose start web до создания контейнеров возникала ошибка service "api" has no container to start. Исправлено предварительным развёртыванием через docker compose up -d.
Ответ на вопрос из задания: Команда up создаёт и запускает контейнеры, тогда как start работает только с уже созданными, но остановленными контейнерами.
Использованные источники и помощь, в том числе ИИ: Официальная документация Docker Compose, помощь ИИ-ассистента.

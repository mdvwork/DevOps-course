# K3-02 — Первый запуск GitHub Actions

## Цель

Создать workflow Student CI по шаблону преподавателя и проверить его запуск после отправки ветки в GitHub.

## Конфигурация

- Файл workflow: `.github/workflows/student-ci.yml`
- Имя workflow: `Student CI`
- События запуска: `push`, `pull_request`
- Runner: `ubuntu-latest`
- Версия Python: `3.13`
- Разрешения: `contents: read`
- Checkout: `actions/checkout` с закреплённым SHA и `persist-credentials: false`
- Настройка Python: `actions/setup-python` с закреплённым SHA

## Результат запуска

- Коммит: `b7d1c99` — `Add initial Student CI workflow`
- Событие: `push` ветки `kt3`
- Workflow: `Student CI`
- Итоговый статус: Success
- Задание: `test`
- Время выполнения задания: 6 секунд
- Проверки шагов: настройка job, checkout, настройка Python 3.13, `python --version` — все успешно завершились.

## Ограничения текущего этапа

На этом этапе workflow подтверждает, что GitHub Actions получает исходный код и настраивает Python 3.13. Автоматический запуск `tests/test_app.py` ещё не добавлен; он будет реализован в K3-03. Сборка Docker-образа будет добавлена в K3-04 отдельным job, зависящим от успешного выполнения тестов.

# K2-02 — Собственный Docker-образ и контейнер

## 1. Создание Dockerfile

Создан файл `lab/Dockerfile` на основе учебного шаблона.

В Dockerfile используются:

- `FROM python:3.13-slim-bookworm` — базовый образ Python.
- `WORKDIR /app` — рабочая директория приложения.
- `COPY app.py index.html ./` — копирование файлов приложения.
- `RUN mkdir /data && chown 10001:10001 /data` — создание каталога данных и назначение владельца.
- `USER 10001:10001` — запуск приложения не от root.
- `EXPOSE 8000` — документирование порта приложения внутри контейнера.
- `LABEL course.student="student-A"` — метка с кодом студента.
- `CMD ["python", "app.py"]` — команда запуска приложения.

## 2. Сборка образа

Выполнена команда:

```bash
docker build -f lab/Dockerfile -t devops-student:v1 lab

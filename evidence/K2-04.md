# K2-04. Registry

- Группа и код студента: 
- Команды: `docker compose --profile registry up -d registry`, `docker tag devops-student:v1 localhost:5000/workshop:v1`, `docker push localhost:5000/workshop:v1`, `docker pull localhost:5000/workshop:v1`, `docker image inspect localhost:5000/workshop:v1`.
- Наблюдения: локальный registry запущен на `127.0.0.1:5000`; `push` завершился сообщением `v1: digest: sha256:bc2c0b9604ee881cf9685e8e26ed2ef67bc04d32603699a4ed4885aff5e5d67b size: 856`; `pull` вернул тот же digest и `Image is up to date`; inspect показал `localhost:5000/workshop@sha256:bc2c0b9604ee881cf9685e8e26ed2ef67bc04d32603699a4ed4885aff5e5d67b`.
- Вывод: тег `v1` — изменяемое имя версии, digest указывает точное содержимое образа. Повторная загрузка всех слоёв не потребовалась, поскольку они уже были локально.
- Ответ на вопрос: `docker push` только отправляет образ в registry; запуск контейнера — отдельное действие.

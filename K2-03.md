# K2-03. Compose и сохранность заявок

Группа: ФЭ-9.24.1

В `compose.student.yaml` для `web` и `api` указан мой образ `devops-student:v1`. После `docker compose stop` проверил файл командой `docker compose -f compose.student.yaml config` и запустил приложение: `docker compose -f compose.student.yaml up -d`. Оба контейнера заработали.

Через страницу отправил заявку №9 «Не работает экран». Потом пересоздал `api` командой `docker compose -f compose.student.yaml up -d --no-deps --force-recreate api`. Заявка №9 осталась в списке. После этого отправил заявку №10 «Не запускается программа» — она тоже появилась.

`web` обращается к `api` по адресу `http://api:8000`: это имя и порт сервиса внутри Docker. Заявки лежат в томе `requests`, поэтому при замене контейнера они не пропали. Без отдельного тома база внутри старого контейнера была бы потеряна.

Чтобы снова открыть приложение: в папке проекта выполнить `docker compose -f compose.student.yaml up -d`, затем перейти на `http://localhost:8080`.

# K2-02. Свой Dockerfile

Группа: ФЭ-9.24.1

Я создал `lab/Dockerfile` и выполнил `docker build -f lab/Dockerfile -t devops-student:v1 lab`. Образ собрался. Команда `docker image inspect devops-student:v1` показала пользователя `10001:10001` и метку `course.student=17092008`.

Запустил контейнер командой `docker run --rm -d --name student-web -p 127.0.0.1:8081:8000 -e ROLE=web devops-student:v1`. По адресу `http://localhost:8081/health` получила `{"process": "running", "role": "web"}`. В `docker logs student-web` был запуск приложения и ответ 200 на `/health`. Затем я остановил контейнер командой `docker stop student-web`.

В Dockerfile `COPY` добавляет файлы приложения, а `CMD` запускает его. `USER` задаёт пользователя без прав администратора; ему разрешена запись в `/data`. `EXPOSE 8000` указывает порт внутри контейнера.

Использовал задание `practicals/KT2.md`, шаблон `templates/Dockerfile.example` и немного помощи клода.

# K2-04. Registry

Группа: ФЭ-9.24.1

Запустил локальный registry командой `docker compose --profile registry up -d registry`. Затем выполнил `docker tag devops-student:v1 localhost:5000/workshop:v1`, `docker push localhost:5000/workshop:v1` и `docker pull localhost:5000/workshop:v1`. Отправка прошла успешно. При скачивании Docker сообщил, что такой образ уже есть на компьютере. Команда `docker image inspect localhost:5000/workshop:v1` нашла его.

Digest отправленного образа: `sha256:67a892bb711bd4aacf5989eb55b9d08f9136b236718db99de2b7b98373bf36b7`.

`v1` — это название версии, его можно перенести на другой образ. Digest указывает на конкретный отправленный образ. `docker push` только сохраняет образ в registry, приложение от этого не запускается.

Использовал задание `practicals/KT2.md` и немного помощи клода.

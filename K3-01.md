# K3-01. CI/CD и ветки

Запуск Actions для этого отчёта ещё не нужен: здесь только маршрут изменений.

## Четыре разных действия

Учебное приложение заявок не выкатывается само по себе.

| Участок | Что это в проекте |
| --- | --- |
| Событие | `push` и `pull_request` у workflow `Student CI` |
| Автоматический тест | job `test`, файл `tests/test_app.py` |
| Сборка | job `build`, команда `docker build` по `lab/Dockerfile` |
| Решение о выпуске | слияние PR в `main` своей копии, его делает человек |

Тест отвечает на вопрос «контракт сервиса ещё держится?». Сборка отвечает на вопрос «из этого коммита вообще получается образ?». Выпуск — отдельное решение слить ветку. Эти три ответа не заменяют друг друга.

Если тест или сборка падают, сообщение появляется в журнале соответствующего шага на GitHub ещё до слияния. Автор ветки видит красный статус на PR и правит код там же.

## Путь коммита

```text
kt3  --commit-->  PR (base: main своей копии)
                         |
                         v
                  Student CI на SHA этого PR
                         |
            test failed  |  test и build зелёные
                 |       |          |
                 v       |          v
            build skipped|     можно сливать в main
```

Короткая ветка не живёт всё полугодие. После приёмки её сливают, следующая работа начинается от обновлённого `main`.

## Сравнение с Git-flow

В Git-flow есть постоянная `develop`, от неё feature-ветки, потом release-ветка и hotfix прямо в `main` с обратным слиянием. Это нужно команде, которая одновременно чинит прод и готовит следующую версию. У этой контрольной одна линия: личная копия курса, одна рабочая ветка `kt3`, одна цель `main`. Вторая долгоживущая ветка ничего не проверяет дополнительно, только путает, куда открывать PR.

## Проверка понимания

Образ после `docker build` — ещё не deployment. Deployment был бы, если бы новый контейнер начал отвечать пользователям на стенде. Здесь job только собирает тег `devops-student:${{ github.sha }}` на временном runner и никуда его не отправляет.
